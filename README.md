# **HM_059_Keyboard_Smashers**

## **🌾 AgriRent – Farmer and Equipment Management System**

---

## **📌 Purpose of the Website**

AgriRent is a digital platform that connects farmers with nearby farm equipment owners, enabling **affordable, transparent, and efficient access** to agricultural machinery through:

* Easy equipment booking
* Secure payments
* Admin-monitored dispute resolution

🎯 **Goal:** Improve farm productivity while reducing idle time of agricultural equipment.

---

## **⚙️ How It Works**

1. **Registration & Login**
   Farmers, equipment owners, and admins create accounts with role-based access.

2. **Equipment Listing**
   Owners list farm machinery with images, pricing, availability, and location.

3. **Search & Booking**
   Farmers search nearby equipment, select time slots, and place booking requests.

4. **Rental & Usage**
   Equipment is used for the confirmed booking duration.

5. **Reviews & Ratings ⭐**
   Farmers and owners rate each other to build trust.

6. **Dispute Management 🛡️**
   Users can raise complaints related to payment, delay, or damage.
   Admin reviews and resolves disputes.

7. **Admin Dashboard**
   Admin monitors:

   * Bookings
   * Disputes
   * Revenue
   * Overall platform activity

---

## **🏫 How It Helps the Institute**

* Reduces **manual coordination** by digitizing listings, bookings, and rental records
* Improves **operational efficiency** through automated scheduling, availability tracking, and payments
* Enhances **trust and transparency** using ratings, reviews, and admin-managed dispute resolution

## **�️ Mapbox Integration Setup**

The farmer dashboard includes a location-based map feature that shows nearby equipment owners within a 50km radius. To enable this feature:

### **1. Get a Mapbox Access Token**
1. Visit [https://account.mapbox.com/](https://account.mapbox.com/)
2. Sign up for a free account
3. Create a new access token
4. Copy the token

### **2. Configure Environment Variables**
1. Copy `.env.example` to `.env` in the frontend directory:
   ```bash
   cp frontend/.env.example frontend/.env
   ```
2. Add your Mapbox token to `frontend/.env`:
   ```
   VITE_MAPBOX_ACCESS_TOKEN=your_actual_mapbox_token_here
   ```

### **3. Features**
- **Farmer Location**: Blue marker showing the farmer's current location
- **Nearby Owners**: Red markers showing equipment owners within 50km
- **Distance Calculation**: Haversine formula for accurate distance measurement
- **Geocoding**: Converts addresses (village, taluka, district, state) to coordinates
- **Interactive Popups**: Click markers to see owner details and available equipment
